## Validation and memory

Tests run in separate processes, sequentially. The complete run passes 46 tests, including the three-epoch training smoke test and the archived pilot posterior value/gradient comparison. One NUTS diagnostics test is skipped because that optional artifact group is not installed here. The core release inputs were recovered from existing local release archives and all 53 files matched their frozen hashes. An anonymous release download returned HTTP 404, so this review does not establish anonymous artifact access.

The account has an 8 GiB hard memory limit. A supervisor stops only its own check if the account approaches 7 GiB or its process group exceeds 2,200 MiB. Interrupted attempts are retained separately and are not counted as successful tests. For the full pilot gradient test, `GEOUNO_TEST_RECOMPUTE=1` recomputes network activations while preserving the original batch sizes and arithmetic. It passes the original archived value and gradient tolerances with an observed process peak of approximately 1.70 GiB.

The equivalence checker now compares lossless temporary snapshots so only one full posterior is resident at a time. Its optional `--low-memory` mode recomputes activations. It retains independent model/data loads, the archived implementations, original batch shapes and existing equality criteria. Current results and memory measurements are recorded under [`provenance/review_20261007`](../provenance/review_20261007).

The complete 53-check comparison passes on `alphacpu01`, Slurm job `125214`, using one CPU thread and a separate 4 GiB allocation. It finishes in 5 min 21 s with a measured process peak of 1,721,784 KiB (approximately 1.64 GiB). This includes all three posterior gradients, MAP, the small real-posterior NUTS comparison, monitoring design and training components. No frozen scientific source is edited.

An independently installed wheel, imported from `/tmp` outside the checkout, passes all 80 supported paper-number checks, all 23 Source Data hashes, task-score loading and the old/new class alias check. Ruff passes. These tests check the supported comparisons and implementation; they do not retrain the published models or repeat the full FE/NUTS study.
